# Paradise Nursery

Paradise Nursery is an intuitive e-commerce web application designed for houseplant enthusiasts to browse, search, and purchase indoor plants. Built with **React** and state-managed using **Redux Toolkit**, the application provides a smooth and responsive shopping experience across all screen sizes.

---

## Key Features

- **Landing Page**: Features a hero background image, company introduction, and a "Get Started" call-to-action button to enter the store.
- **Product Catalog**: Organizes 18 unique houseplants into 3 main categories (*Air Purifying*, *Aromatic*, and *Low Maintenance*) with details on light requirements, watering schedules, and prices.
- **Redux Shopping Cart**:
  - Real-time cart badge counter in the navigation bar.
  - Disables the "Add to Cart" button once an item is added to prevent duplicate entries.
  - Allows users to increase, decrease, or remove item quantities directly from the cart view.
  - Automatically updates unit totals and overall cart cost calculations.
- **About Us**: Clean summary highlighting Paradise Nursery’s mission to make homes greener.
- **Responsive UI**: Styled in leaf-green eco-friendly tones, fully responsive for desktop, tablet, and mobile devices.

---

## Technologies Used

- **React**: Functional components and hooks (`useState`, `useEffect`, `useSelector`, `useDispatch`)
- **Redux Toolkit**: Centralized state management using `createSlice` for shopping cart operations
- **CSS3**: Custom styling with Flexbox and CSS Grid
- **JavaScript (ES6+)**: Modern JavaScript syntax and modular structure
